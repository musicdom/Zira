# Zira — «Моё меню»

Мобильный каталог информационного продукта «60 готовых блюд».

## Что уже сделано

- 60 карточек: 20 завтраков, 20 обедов, 20 ужинов.
- Поиск по блюдам.
- Фильтрация по категориям.
- Карточка рецепта с калориями, БЖУ, ингредиентами и шагами.
- Адаптивный мобильный интерфейс.
- Экран покупки за 1 490 ₽.
- Архитектура без регистрации, личного кабинета и сложной CRM.

## Важный момент про доступ

Сейчас это фронтенд-прототип. Настоящую защиту материалов нельзя надёжно сделать только статическим HTML: URL страницы должен выдаваться ботом после подтверждённой оплаты.

Рекомендуемый поток:

Instagram → Telegram-бот → оплата 1 490 ₽ → бот получает подтверждение → выдаёт персональную ссылку → каталог.

Кнопка покупки в прототипе ведёт на Telegram и является точкой подключения реального бота.

## Контент

Текущие рецепты — демонстрационная структура интерфейса. Перед продажей заменить названия/ингредиенты/БЖУ на фактический контент продукта и добавить реальные фотографии блюд.
